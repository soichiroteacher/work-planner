# 仕事管理(分掌・学年・学校全体)

仕事の予定・進み具合・仕事量の偏りを見える形にし、定例会のレジュメも作れるアプリです(4つの段階まで作りました。使ってみて直したいところがあれば、担当の開発者に伝えてください)。

分掌・学年・学校全体の仕事を「プロジェクト」と「小業務」に分けて入力し、ガントチャートで時期と進み具合を見えるようにするアプリです。

## 使う前に

- **Chrome か Edge** で開いてください(ほかのブラウザでは保存できません)。
- アプリ(`index.html`)と、分掌・学年ごとのデータファイル(`.json`)を、校務共有サーバーの同じフォルダに置いて使います。

## 使い方

### はじめて使うとき(データファイルを作る)

1. `index.html` をダブルクリックして開きます。
2. 「新規作成」を押し(2回目からは、右上の「ファイル ▼」の中にあります)、種類(分掌/学年/学校全体)・名前(例：教務部)・年度を入れて「作る」を押します。
3. 保存する場所を聞かれるので、校務共有サーバーのフォルダを選びます。ファイル名は `仕事管理_教務部_2026.json` のようになります。
4. 「設定」タブの「メンバー」に、担当者の名前を入れます。

どんなアプリか試したいときは、最初の画面の「見本を表示する」を押してください(見本は保存されません)。

### ふだん使うとき

- 開くと、前回のデータファイルがそのまま表示されます(「前回のファイルを開く」ボタンが出たら、押してください)。
- 入力するときは、上の「✏ 編集する」を押し、名前を入れます。**編集できるのは1人ずつ**です。編集中は、ほかの先生の画面に「○○先生が編集中」と出ます。
- 入力した内容は、自動で保存されます。終わったら、必ず「**編集を終える**」を押してください。
- 見ているだけの先生は、「ファイル ▼」→「↻ 最新の内容にする」を押すと、ほかの先生が保存した最新の内容が表示されます。
- 「編集する」を押したときの**お名前は必ず入れてください**(空のままでは始められません)。一度入れた名前は、次から最初から入っています。
- 「ファイル ▼」→「**編集の記録**」を押すと、**だれが・いつ編集したか**が新しい順に出ます(名前・日付・始めた時刻〜最後に保存した時刻)。何を変えたかは残りません。新しいものから200件まで残ります。見本で試しているときは記録されません。
- 使い方は、右上の「**？ 使い方**」でも見られます。「見本で試す」を押すと、架空のデータで操作を試せます。

### ガントチャート

- 左にプロジェクトと小業務の名前、右に期間の横棒が出ます。赤い縦線が今日です。
- 横棒の塗り方で進み具合が分かります(白＝未着手、しま模様＝作業中、灰色＝完了)。期限を過ぎて終わっていないものは赤く「期限切れ」と出ます。 担当の名前は横棒の横に出ます(入らないときは左の名前の横)。
- 上の帯には、「✏ 編集する」「ファイル ▼」「？ 使い方」だけを出しています。開く・新規作成・前年度から作る・まとめて見る・編集の記録は「**ファイル ▼**」の中にあります。「保存」は編集中だけ出ます。
- 記号(横棒の塗り方・◆・○ など)の意味は、ガントチャートの上の「**記号の見方**」を押すと出ます。
- 「月ごと・週ごと・日ごと」で、目盛りの細かさを変えられます。
- 「担当者」で、その先生の仕事だけにしぼれます。「完了を隠す」で、終わった仕事を隠せます。
- プロジェクトの左の ▼/▶ で、小業務を開いたり閉じたりできます。 「すべて閉じる」(閉じているときは「すべて開く」)で、まとめて開け閉めできます。
- 名前か横棒を押すと、内容・注意点のメモを見たり、直したりできます。⚠ の印は、注意点が書いてあるものです。

### 毎週・毎月の仕事(くり返し)

- 小業務の入力画面の「**くり返し**」で、次の中から選びます。
  - **毎週**(曜日を選ぶ。月・木のように2つ以上も選べます)
  - **毎月○日**(31にすると毎月の末日)
  - **毎月第○○曜日**(第1〜第4・最終)
  - **日付を自分で選ぶ**(学期に1回など、決まった形にならないもの)
- 夏休みなどで止める月は「**お休みの月**」に印を付けます。途中から始まる・途中で終わるときは「くり返す期間」を入れます(空なら年度の初めから終わりまで)。
- ガントチャートでは、1行に各回の ○ が並びます(名前の前に 🔁)。済んだ回は灰色、過ぎてまだ済んでいない回は赤で、「期限切れ」と出ます。
- **済んだ回の印の付け方**: 「編集する」を押してから、ガントチャートの ○ を押します(もう一度押すと「まだ」に戻ります)。入力画面の「済んだ回」でも付けられます。「今日までの回をすべて「済」にする」ボタンもあります。
- 進み具合(未着手・作業中・完了)は、済んだ回の数から自動で決まります。名前の横の「6/11回」は、済んだ回 / 全部の回です。

### 仕事量の表(仕事の偏りを見る)

- ガントチャートの上の「**仕事量の表**」に印を付けると、ガントチャートの下に、先生ごと・月ごとの仕事量の表が出ます。
- 数字は、その月にかかっている仕事の重さ(軽い＝1、ふつう＝2、重い＝3)の合計です。4〜6月の「重い」仕事なら、4月・5月・6月にそれぞれ3を足します。2人で担当する仕事は、2人ともに数えます。完了した仕事も数えます。 ただし🔁 毎週・毎月の仕事は、その月にある回の数だけ足します(毎週の「軽い」が月4回なら4)。
- 色が濃いほど、仕事が多い月です。いちばん右の「合計」で、1年間の仕事の量を先生どうしで比べられます。
- 先生の名前を押すと、ガントチャートがその先生の仕事だけになります(もう一度押すと全員に戻ります)。

### 印刷(掲示・配布)

1. ガントチャートの上の「**🖨 印刷**」を押します。
2. 次のことを選びます。
   - **用紙**: A3横(職員室などへの掲示用。文字が大きい)か、A4横(配布用)
   - **期間**: 何月から何月までか。「今月と来月」「1年間」のボタンでも選べます
   - **担当者**: 全員か、1人の先生
   - **プロジェクト**: 印刷するプロジェクトに印を付けます(一部だけの印刷もできます)
   - **完了した仕事も印刷する** / **仕事量の表も印刷する** / **1枚に収める**(仕事が多いと文字が小さくなります)
3. 「印刷する」を押すと印刷の画面が開きます。PDF にするときは、送り先で「PDF に保存」を選んでください。
- 白黒で印刷しても、横棒の塗り方と「作業中」「完了」「期限切れ」の文字で進み具合が分かります。赤い点線は印刷した日です。
- A3 で印刷するには、プリンタが A3 に対応している必要があります。
- 「印刷」ボタンを使わずに Ctrl＋P で印刷したときは、1年間・全部のプロジェクトを、前回選んだ用紙で印刷します。

### 仕事の一覧

- 表の形で仕事を見ます。**列の見出しを押すと並べ替え**ます(もう一度押すと逆の順)。
- 編集中は、「進み具合」をその場で変えられます。
- 「プロジェクトごとにまとめる」を外すと、全部の小業務を1つの表で並べ替えられます。

### 定例会レジュメ

1. 「**定例会レジュメ**」タブを開き、「編集する」を押してから「**＋ 新しいレジュメを作る**」を押します。
   - 会議の日は、「設定」の「定例会の曜日」から、今日以降のいちばん近い日になります。次回は1週間後です。どちらも、日付の欄で直せます。
2. ガントチャートの仕事から、次の4つが自動で入ります。
   - **報告**: 前回の会議から今回までに完了した仕事(完了にした日で数えます)と、済んだ毎週・毎月の仕事の回
   - **確認**: 今回から次回の会議までに、期限が来る・始まる仕事と、毎週・毎月の仕事の回
   - **要相談**: 期限を過ぎて、まだ終わっていない仕事
   - **近づいている行事**: 1か月以内に当日が来るプロジェクト
3. 必要なら、各行の「メモ」に書き足します。「**＋ 行を書き足す**」で、自分で行を足すこともできます。いらない行は ✕ で消せます。
4. 「協議事項」「連絡事項」を書き、「**🖨 印刷(A4縦)**」で印刷します。PDF にするときは、送り先で「PDF に保存」を選びます。
5. 会議のあとに「**決定事項**」を書きます。次の会のレジュメを作ると、「前回の決定事項」に写されます。決定事項が空のまま印刷すると、手で書ける罫線の欄になります。

- 仕事の進み具合を直したあとや、会議の日を変えたあとは「**仕事を取り込み直す**」を押してください。手で足した行と、メモはそのまま残ります。
- レジュメは会議ごとにデータファイルに保存され、上の一覧から前の会のレジュメも見られます。取り込んだ内容は作ったときの写しなので、あとで仕事を直しても、前の会のレジュメは変わりません(取り込み直したときだけ変わります)。

### 入力のしかた

- 「＋ プロジェクト」で大きな仕事(例：入学式)を作り、「＋ 小業務」でその中の仕事(例：式次第の作成)を入れます。
- プロジェクトには、**期間**と**当日**も入れられます(どちらも入れなくてかまいません)。
  - **期間**: 入れないときは、中の小業務の期間から自動で決まります。小業務をまだ分けていないうちに、大まかな時期を並べておきたいときに入れてください。
  - **当日**: 行事の本番の日や、提出の締め切り日です。1日だけなら左の欄だけ入れます。2日以上続く行事(例：学校公開が2日間)は、終わりの日も入れます。ガントチャートと印刷に ◆(2日以上は黒い帯)と「当日 6/12(金)〜6/13(土)」が出ます。
  - 小業務がプロジェクトの期間からはみ出すと、「**期間外**」と出ます。入力ミスに気づくためのお知らせで、そのままでも使えます。
- 入れた日付を空に戻すときは、日付の欄の横の「**消す**」ボタンを押します(プロジェクトの期間・当日、小業務の期間)。
- 小業務には、担当・期間・進み具合・仕事量(軽い/ふつう/重い)・内容のメモ・注意点を入れられます。
- 「毎年くり返す」に印を付けた仕事は、次の年度の一覧を作るときに写されます。
- 削除するときは、確認のメッセージが出ます。削除したものは元に戻せません。

### 前年度から作る(新しい年度のはじめに)

1. 「ファイル ▼」→「**前年度から作る**」を押します(最初の画面の「前年度から作る」からも開けます)。
2. 元にするファイルを選びます。今開いているファイルを使うか、「ほかのファイルを選ぶ」で前年度のファイルを選びます。
3. 写すものの数を確かめて「作る」を押し、新しいファイルの保存先を選びます(例：`仕事管理_教務部_2027.json`)。

- 写すのは、「**毎年くり返す**」に印が付いているプロジェクトと小業務だけです。
- 日付は「**同じ週の同じ曜日**」にそろえます(例：2026/4/7(火) → 2027/4/6(火))。毎週・毎月の仕事は、決まりをそのまま写します。
- 進み具合は「未着手」に戻します。担当・メモ・注意点・メンバー・設定はそのまま写します。**担当が替わった仕事は、「仕事の一覧」で直してください。**
- 定例会レジュメと編集の記録は写しません。前年度のファイルは書き換えません。

### まとめて見る(学校全体)

1. 「ファイル ▼」→「**まとめて見る(学校全体)**」を押し、分掌・学年のデータファイルを選びます(Ctrl キーを押しながらクリックすると、いくつも選べます)。
2. プロジェクトの名前の前に【教務部】のように分掌・学年の名前が付いて、まとめて表示されます。

- **見るだけ**です。直すときは、「ファイル ▼」→「開く」でそれぞれの分掌・学年のファイルを開いてください。
- **同じ名前の先生は同じ人**として数えます。仕事量の表で、分掌・学年をまたいだ仕事の偏りが見えます(同じ先生の名前は、どのファイルでも同じ書き方にしてください)。
- 「🖨 印刷」で、学校全体のガントチャートを A3 で印刷して掲示できます。
- 年度が違うファイルは入りません(最初に選んだファイルの年度にそろえます)。定例会レジュメは使えません。

## データの保存場所

- データは、分掌・学年ごとのデータファイル(`.json`)に保存されます。校務共有サーバーに置いてください。
- 年度ごとに別のファイルにします。
- 先生の名前などの実データは校内でだけ扱います。インターネットやクラウドには置きません。
- 念のため、ブラウザの中にも最後に入力した内容の控えが残りますが、これには頼らないでください。

## バックアップと復元

- 「設定」タブの「**データを書き出す(バックアップ)**」を押すと、`仕事管理_バックアップ_教務部_2026-09-27.json` のような日付入りのファイルがダウンロードされます。学期の終わりなど、区切りごとに書き出して、共有サーバーの別のフォルダに置いておいてください。
- 元に戻すときは、「編集する」を押してから「**データを読み込む(復元)**」を押し、バックアップのファイルを選びます。今のデータは、読み込んだ内容で置き換わります。

## 困ったとき

| こんなとき | どうすればよいか |
|---|---|
| 「保存できませんでした」と出る | 共有サーバーにつながっているか確かめてから、「保存」を押してください。 |
| 「○○先生が編集中」と出て編集できない | その先生が「編集を終える」を押すまで待ってください。ブラウザを閉じ忘れている場合は、15分たつと表示が消えます。 |
| 「ほかの人が保存しています」と出る | 同じファイルをほかの場所で直した人がいます。「キャンセル」を押し、入力した内容を控えてから、ページを開き直してください。 |
| パスワードを忘れた | 担当の開発者に相談してください。 |
| ファイルが壊れた・消えた | 「データを読み込む(復元)」で、バックアップから戻してください。 |
