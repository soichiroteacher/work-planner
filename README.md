# 仕事管理(分掌・学年・学校全体)

**作成中です(まだ使えません)。** 下は、これから作るアプリの説明です。

分掌・学年・学校全体の仕事を「プロジェクト」と「小業務」に分けて入力し、ガントチャートで時期と進み具合を見えるようにするアプリです。
定例会のレジュメも、このアプリで作れるようにします。

## できるようにすること

- 仕事の一覧と時期・担当者・進み具合を入力し、ガントチャートで見る
- 大きなプロジェクトの下に、小業務をまとめて管理する
- 一覧を自由に並べ替える。終わった仕事は隠せる
- 仕事量の程度(数段階)を付けて、担当者ごとの偏りを見る
- プロジェクトや小業務ごとに、内容・注意点をメモしておく
- 前年度のデータから、今年度の一覧を自動で作る
- 全体または一部を印刷して、配布・掲示する
- 定例会のレジュメを作って印刷する(PDF にもできる)
