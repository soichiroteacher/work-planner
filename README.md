# 仕事管理(分掌・学年・学校全体)

**作成中です。** いまは「ガントチャート」「仕事の一覧」「設定」が使えます。仕事量の表示・印刷・定例会レジュメ・前年度から作る機能は、これから作ります。

分掌・学年・学校全体の仕事を「プロジェクト」と「小業務」に分けて入力し、ガントチャートで時期と進み具合を見えるようにするアプリです。

## 使う前に

- **Chrome か Edge** で開いてください(ほかのブラウザでは保存できません)。
- アプリ(`index.html`)と、分掌・学年ごとのデータファイル(`.json`)を、校務共有サーバーの同じフォルダに置いて使います。

## 使い方

### はじめて使うとき(データファイルを作る)

1. `index.html` をダブルクリックして開きます。
2. 「新規作成」を押し、種類(分掌/学年/学校全体)・名前(例：教務部)・年度を入れて「作る」を押します。
3. 保存する場所を聞かれるので、校務共有サーバーのフォルダを選びます。ファイル名は `仕事管理_教務部_2026.json` のようになります。
4. 「設定」タブの「メンバー」に、担当者の名前を入れます。

どんなアプリか試したいときは、最初の画面の「見本を表示する」を押してください(見本は保存されません)。

### ふだん使うとき

- 開くと、前回のデータファイルがそのまま表示されます(「前回のファイルを開く」ボタンが出たら、押してください)。
- 入力するときは、上の「✏ 編集する」を押し、名前を入れます。**編集できるのは1人ずつ**です。編集中は、ほかの先生の画面に「○○先生が編集中」と出ます。
- 入力した内容は、自動で保存されます。終わったら、必ず「**編集を終える**」を押してください。
- 見ているだけの先生は、「↻ 最新にする」を押すと、ほかの先生が保存した最新の内容が表示されます。

### ガントチャート

- 左にプロジェクトと小業務の名前、右に期間の横棒が出ます。赤い縦線が今日です。
- 横棒の塗り方で進み具合が分かります(白＝未着手、しま模様＝作業中、灰色＝完了)。期限を過ぎて終わっていないものは赤く「期限切れ」と出ます。
- 「月ごと・週ごと・日ごと」で、目盛りの細かさを変えられます。
- 「担当者」で、その先生の仕事だけにしぼれます。「完了を隠す」で、終わった仕事を隠せます。
- プロジェクトの左の ▼/▶ で、小業務を開いたり閉じたりできます。
- 名前か横棒を押すと、内容・注意点のメモを見たり、直したりできます。⚠ の印は、注意点が書いてあるものです。

### 仕事の一覧

- 表の形で仕事を見ます。**列の見出しを押すと並べ替え**ます(もう一度押すと逆の順)。
- 編集中は、「進み具合」をその場で変えられます。
- 「プロジェクトごとにまとめる」を外すと、全部の小業務を1つの表で並べ替えられます。

### 入力のしかた

- 「＋ プロジェクトを追加」で大きな仕事(例：入学式)を作り、「＋ 小業務」でその中の仕事(例：式次第の作成)を入れます。
- 小業務には、担当・期間・進み具合・仕事量(軽い/ふつう/重い)・内容のメモ・注意点を入れられます。
- 「毎年くり返す」に印を付けた仕事は、次の年度の一覧を作るときに写されます(この機能はこれから作ります)。
- 削除するときは、確認のメッセージが出ます。削除したものは元に戻せません。

## データの保存場所

- データは、分掌・学年ごとのデータファイル(`.json`)に保存されます。校務共有サーバーに置いてください。
- 年度ごとに別のファイルにします。
- 先生の名前などの実データは校内でだけ扱います。インターネットやクラウドには置きません。
- 念のため、ブラウザの中にも最後に入力した内容の控えが残りますが、これには頼らないでください。

## バックアップと復元

- 「設定」タブの「**データを書き出す(バックアップ)**」を押すと、`仕事管理_バックアップ_教務部_2026-09-27.json` のような日付入りのファイルがダウンロードされます。学期の終わりなど、区切りごとに書き出して、共有サーバーの別のフォルダに置いておいてください。
- 元に戻すときは、「編集する」を押してから「**データを読み込む(復元)**」を押し、バックアップのファイルを選びます。今のデータは、読み込んだ内容で置き換わります。

## 困ったとき

| こんなとき | どうすればよいか |
|---|---|
| 「保存できませんでした」と出る | 共有サーバーにつながっているか確かめてから、「保存」を押してください。 |
| 「○○先生が編集中」と出て編集できない | その先生が「編集を終える」を押すまで待ってください。ブラウザを閉じ忘れている場合は、15分たつと表示が消えます。 |
| 「ほかの人が保存しています」と出る | 同じファイルをほかの場所で直した人がいます。「キャンセル」を押し、入力した内容を控えてから、ページを開き直してください。 |
| パスワードを忘れた | 担当の開発者に相談してください。 |
| ファイルが壊れた・消えた | 「データを読み込む(復元)」で、バックアップから戻してください。 |
